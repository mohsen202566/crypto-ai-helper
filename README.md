# ربات ورود پله‌ای (Staged Entry Bot)

ربات معاملاتی تک‌ارزی با ورود پله‌ای در جهت روند، مدیریت ریسک ریاضی و کنترل تلگرام.

## نصب روی سرور

```bash
mkdir -p /root/staged-bot && cd /root/staged-bot
# فایل‌های پروژه را اینجا کپی کنید
pip install -r requirements.txt --break-system-packages

cp .env.example .env
nano .env          # کلیدها را وارد کنید
chmod 600 .env     # فقط root بتواند بخواند
```

## اجرای دائمی با systemd (خودکار روشن می‌شود اگر خاموش شود)

```bash
cp staged-bot.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable staged-bot
systemctl start staged-bot
```

بررسی وضعیت و لاگ:
```bash
systemctl status staged-bot
journalctl -u staged-bot -f
```

## دستورات تلگرام

| دستور | کار |
|---|---|
| `پنل` | پنل ترید (موجودی، سرمایهٔ درگیر، PnL) |
| `آمار` | آمار کامل، واقعی و مجازی جدا |
| `پوزیشن` | پوزیشن‌های باز |
| `ترید فعال` | روشن کردن ترید واقعی |
| `ترید خاموش` | بازگشت به حالت مجازی |
| `پله ۳` | تنظیم حداکثر تعداد پله |
| `سقف ۵۰` | سقف سرمایهٔ درگیر (۰ = کل موجودی) |
| `وضعیت` | سلامت سیستم |

## منطق ایمنی

سرمایه **همیشه زنده** از صرافی خوانده می‌شود، نه عدد ثابت.

سه لایهٔ محافظت:
1. مجموع مارجین همهٔ پله‌ها هرگز از `MAX_CAPITAL_ENGAGED_RATE` (پیش‌فرض ۵۰٪) موجودی بیشتر نمی‌شود.
2. لوریج خودکار انتخاب می‌شود — **کم‌ریسک‌ترین** لوریجی که هنوز سود معنادار بدهد.
3. حد ضرر سخت همیشه حداقل ۲ برابر زودتر از لیکوئید فعال می‌شود.

### نکتهٔ مهم دربارهٔ لیکوئید
فاصلهٔ لیکوئید ریاضاً ≈ ۱÷لوریج است و با اضافه شدن پله **دورتر نمی‌شود**:

| لوریج | فاصلهٔ لیکوئید |
|---|---|
| ۱x | ۹۹.۵٪ |
| ۳x | ۳۳.۲٪ |
| ۵x | ۱۹.۹٪ |
| ۱۰x | ۹.۹٪ |

پس «لیکوئید غیرممکن» با فاصلهٔ بزرگ به دست نمی‌آید (آن فقط لوریج ۱ را مجاز می‌کند
که سودش از کارمزد کمتر است). محافظت واقعی این است که **حد ضرر خیلی زودتر
فعال شود** — اگر استاپ روی ۷٪ و لیکوئید روی ۳۳٪ باشد، عملاً هرگز به لیکوئید نمی‌رسید.

## هشدار
هیچ استراتژی‌ای سود را تضمین نمی‌کند. این ربات ریسک را *محدود و شفاف* می‌کند،
نه *حذف*. حتماً هفته‌ها در حالت مجازی اجرا کنید و آمار واقعی را ببینید
قبل از اینکه `ترید فعال` بزنید.
